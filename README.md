# SauceDemo Manual Testing Project

## 📌 Project Overview

This is a personal Manual Software Testing project performed on the SauceDemo / Swag Labs e-commerce web application.

The project was created to practice the end-to-end manual QA process, including test case design, test execution, defect identification, bug reporting, and test result documentation.

## 🎯 Testing Scope

The following modules were tested:

- Login
- Products
- Shopping Cart
- Checkout
- Menu / Navigation

## 🧪 Testing Approach

Testing activities included:

- Functional Testing
- Positive & Negative Testing
- UI and Content Validation
- Input Validation
- Exploratory Testing
- Test Case Design & Execution
- Bug Reporting
- Severity & Priority Assessment

## 🐞 Defects Identified

Four confirmed defects were documented during testing:

- Login error message is partially cut off.
- Product description contains unexpected code-like text.
- Product name contains unexpected code-like text.
- Product state is not reset consistently after using Reset App State.

Detailed reproduction steps, expected results, actual results, severity, priority, and evidence are documented in the Excel project file.
